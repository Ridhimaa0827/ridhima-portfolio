# Ridhima Sharma — Portfolio

A responsive React + Vite portfolio with custom CSS. The design uses warm off-white, charcoal, and muted terracotta — no purple gradients.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown by Vite.

## Before publishing
- Check each project's Live Preview and Source Code links in `src/main.jsx`.
- Food Delivery and Fitness Hub currently use your GitHub profile as the source link because exact repository URLs weren't supplied.
- If a live demo URL is available for either project, replace `#contact` with that URL.
- Your resume PDF and profile photo are included in `public/` if they were available with the upload.
- For deployment, run `npm run build`; upload the project to GitHub and connect it to Vercel.

## Stack
React, Vite, lucide-react, custom responsive CSS.
